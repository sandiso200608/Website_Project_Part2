Ubuntu Fresh Market Website

Project Overview
Ubuntu Fresh Market is a fictional South African grocery retailer based in Durban, KwaZulu-Natal. The website provides customers with business information, products, weekly specials and a contact enquiry form.
Part 2 Improvements
Part 2 extends the Part 1 HTML website with an external CSS stylesheet and a responsive, mobile-first presentation. The improvements include:
Consistent Ubuntu Fresh Market branding and colour scheme.
Responsive navigation and page layouts.
Improved typography, spacing, buttons, cards and tables.
Responsive images using relative sizing and `max-width: 100%`.
A media query below 960px and a mobile breakpoint below 600px.
Touch-friendly navigation and buttons for mobile users.
Improved semantic structure, accessibility labels and descriptive meta tags.
Improved consistency across all five pages.

Responsive Testing
The website should be tested in Google Chrome Developer Tools using desktop, tablet and mobile viewport sizes. The design is intended to avoid horizontal scrolling and to keep navigation and controls usable on a portrait mobile screen.
